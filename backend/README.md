# EduFlowAI-Backend
This is the backend repository of EduFlowAI Platform.

## 🚨🚨 Contribution Guidelines

- No direct commits to the ```main``` branch
- Create your own **Fork** or **Branch** and contribute within it.
- **Branchs Naming Convention** : ```feat/feature_name```, ```fix/bug_name```
- **🚩 Pull Requests(PR) and Code Review** : All changes must be submitted via a PR and cannot be merged until it has been reviewed and approved by at least another team member.
- **🚩 When you Push new commits** : Make sure that there isn’t any opened PRs or new commits on the main branch -pull them first then push your updates via a PR-.

- **Commits Message Convention** :

  ```feat: description``` for new feature or new functionality.
  
  ```fix: description``` for bug and error fixing.
  
  ```refactor: description``` for improving code without changing behavior or re-implement a feature.
  
  ```perf: description``` for performance issues optimizations.
  
  ```style: description``` for formatting and code style fixes.
